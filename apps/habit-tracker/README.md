# Level Up Habit Tracker — Frontend Application

Aplicación SPA moderna de seguimiento de hábitos personales, con diseño Dark Glassmorphism, persistencia en `localStorage`, motor de rachas e insignias de hitos.

## Iniciar Aplicación

```bash
node serve.js
```

Abre en tu navegador: [http://localhost:5173](http://localhost:5173)

## Ejecutar Pruebas

```bash
node tests/storage.test.js
node tests/streakEngine.test.js
node tests/sprint3.test.js
```
